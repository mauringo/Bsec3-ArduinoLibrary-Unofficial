# Examples

Start with **generic_i2c/generic_i2c.ino**. It explains ESP32 custom SDA/SCL GPIOs, board-default pins on other Arduino cores, the sensor address, and the measurement flow. These are Mauro Riboni’s personal hobby examples, made for fun and learning, independent of Bosch.

The sketches in this folder demonstrate this library independently.

For the complete Polverine setup with BME690, BSEC3, BMV080, board profiles, temperature compensation, and Serial JSON:

- [PlatformIO project](https://github.com/mauringo/Polverine_Arduino_Examples)
- [Arduino IDE sketch and setup](https://github.com/mauringo/Polverine_Arduino_Examples/tree/main/Arduino_project)

Follow the library README for installation. BSEC3 requires a separately obtained Bosch SDK.
